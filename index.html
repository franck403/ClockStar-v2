Step 0 • No MicroPython Detected

The installer couldn't find a MicroPython REPL on this device. This can mean one of two things:

Try this first:

  1. Unplug the watch fully (remove USB) and wait 10 seconds.
  2. Hold the reset/boot button (if present) while plugging back in.
  3. Reconnect here and try again.

If it still doesn't respond, use "Install / reinstall MicroPython" below anyway — putting the ESP32-S3 into its ROM bootloader (BOOT button held while plugging in, or via the reset pulse this tool sends) lets esptool talk to it even with no working firmware at all.

Step 0 • Flash MicroPython

Select a MicroPython .bin firmware image built for ESP32-S3 (a combined image flashed at offset 0x0 is expected — e.g. a CircuitMess/MicroPython "firmware.bin" or "GENERIC_S3" build). This will erase the entire flash before writing.
